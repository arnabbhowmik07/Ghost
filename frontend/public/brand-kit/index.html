Rules

Keep it sharp. Keep it Ghost.

Do
  • Use the official path + eyes
  • Pair sun only with ink text
  • Say “prepaid gas,” not “mixer”
  • Leave clear space around the mark
  • Prefer paper / cream fields
Don’t
  • Drop the eyes or stretch the glyph
  • Add glow, blur, or soft shadows
  • Round the corners
  • Put “Devnet” in user-facing UI
  • Swap Instrument for Inter / system UI
